# راهنمای مدیریت پرتال خبری 🛠️

## گردش کار روزانهٔ تحریریه

1. **خبرنگار** از `/admin/news/articles/create` خبر می‌سازد (لید + بدنهٔ
   Markdown + دسته + برچسب + تصویر شاخص/گالری) → «ارسال برای بازبینی».
2. **ویراستار** در `/admin/news/articles?status=review` بازبینی می‌کند:
   - «تأیید» — با فیلد زمان (datetime-local) برای **زمان‌بندی انتشار**
   - «رد» — با ذکر دلیل (برای خبرنگار نمایش داده می‌شود)
3. **سردبیر** خبرهای approved را «انتشار فوری» می‌دهد یا زمان‌بندی‌شده‌ها
   خودکار با cron منتشر می‌شوند:
   `* * * * * php bin/tvn schedule:run`
   (ماژول `news:publish-scheduled` را هر دقیقه ثبت می‌کند)

## خبر فوری 🔴

- دکمهٔ «خبر فوری» روی فرم خبر (فقط published/approved).
- اثر: بنر بالای همهٔ صفحات، اولویت sitemap، cache کوتاه (۱۰s) و
  broadcast روی کانال realtime `news` (برای مشترکین SSE/WS).
- اندپوینت widget: `GET /news/breaking` (JSON).

## دسته‌ها

`/admin/news/categories` — عنوان/slug/والد/توضیح. صفحهٔ دسته **شامل
زیردسته‌ها** هم می‌شود. حذف دسته → زیردسته‌ها ریشه و مقالات بی‌دسته.

## نظرات

`/admin/news/comments` — فیلتر وضعیت، تأیید/اسپم/حذف. نویسندهٔ خوش‌سابقه
(تأیید قبلی) در حالت standard خودکار تأیید می‌شود (config `comment.moderation`).

## کارایی

- پاسخ صفحهٔ خبر **ETag** دارد — درخواست تکراری ۳۰۴ بدون رندر.
- هر ویرایش/انتشار → invalidate کل کش news (tag-based).
- برای ترافیک بالا: `--preset=enterprise` + درایور کش redis + `tvn optimize`.
