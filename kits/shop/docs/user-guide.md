# راهنمای کاربر ویترین فروشگاه

## خرید گام‌به‌گام

1. **مرور**: `/shop` — فیلتر دسته، مرتب‌سازی (جدیدترین/ارزان‌ترین/پرفروش‌ترین)، جست‌وجوی فارسی.
2. **محصول**: صفحهٔ جزئیات — قیمت (با تخفیف)، وضعیت موجودی، انتخاب تنوع (رنگ/سایز)، مشخصات.
3. **سبد**: «افزودن به سبد» → `/shop/cart` — ویرایش تعداد، حذف، اعمال کد تخفیف.
4. **checkout**: ورود به حساب → فرم آدرس ارسال → «ثبت سفارش و پرداخت».
5. **پرداخت**: انتقال به درگاه (در محیط دمو: صفحهٔ شبیه‌ساز با دو دکمهٔ موفق/ناموفق).
6. **پیگیری**: `/shop/orders` — وضعیت (در انتظار پرداخت/پرداخت‌شده/ارسال‌شده/تحویل/لغو/مسترد)، کد رهگیری، لغو تا پیش از ارسال.

## نکته‌ها

- موجودی در لحظهٔ **ثبت سفارش** رزرو می‌شود؛ لغو سفارش موجودی را بازمی‌گرداند.
- پرداخت ناموفق سفارش را حذف نمی‌کند — از «سفارش‌های من» دوباره پرداخت کنید.
- نقد و بررسی پس از تأیید مدیر منتشر می‌شود.
