# راهنمای مدیر فروشگاه

## نقش‌ها (DOC-093 §5)

| نقش | توانایی |
|---|---|
| shop-operator | ساخت/ویرایش محصول، مشاهدهٔ سفارش، مشاهدهٔ نقدها |
| shop-manager | همهٔ موارد + تغییر وضعیت/لغو/استرداد سفارش، کوپن، گزارش، moderation نقدها، حذف |
| inventory-keeper | مشاهدهٔ محصول + تنظیم موجودی |
| admin | همه‌چیز + کاربران |

## کاتالوگ — `/admin/shop/products`

- **ساخت/ویرایش**: عنوان (slug خودکار فارسی)، دسته، قیمت/قیمت فروش (ریال — int)، SKU، موجودی، آستانهٔ هشدار، وزن، ویژگی‌های JSON، توضیحات Markdown، تصویر شاخص (ULID رسانه).
- **تنوع‌ها**: اختلاف قیمت + موجودی مستقل + گزینه‌ها (`{"color":"قرمز"}`).
- **وضعیت**: پیش‌نویس → فعال → بایگانی؛ حذف = soft.
- **تنظیم موجودی**: delta ± با دلیل → در حرکت‌نامه ثبت می‌شود.

## سفارش‌ها — `/admin/shop/orders`

- کارت‌های آمار (پرداخت‌شده‌ها/مجموع فروش)، فیلتر وضعیت/جست‌وجو.
- جزئیات: اقلام snapshot، breakdown مالی، آدرس، حرکت‌های موجودی.
- عملیات: **ارسال** (با کد رهگیری) → **تحویل** • **لغو** (بازگشت موجودی + refund خودکار سفارش پرداخت‌شده) • **استرداد** مدیرتی.
- خروجی CSV: `/admin/shop/orders/sales.csv` (مجوز `shop.report.view`).

## کوپن‌ها — `/admin/shop/coupons`

درصدی (با سقف) یا مبلغ ثابت؛ حداقل سبد، ظرفیت مصرف، انقضا؛ غیرفعال‌سازی بدون حذف.

## نقدها — `/admin/shop/comments`

صف pending → تأیید/اسپم/حذف. متن‌ها هنگام ذخیره با پروفایل `plain` سانیتایز می‌شوند (دفاع در عمق) و در ویو escape.

## پرداخت

- دمو/توسعه: `shop.payment.driver=sandbox` (پیش‌فرض).
- عملیاتی: `driver=engine` + `shop.payment.gateway` (zarinpal/idpay/…) + کلیدهای `.env` — verify همیشه server-to-server با مبلغ سفارش محلی (DOC-120 §5).
