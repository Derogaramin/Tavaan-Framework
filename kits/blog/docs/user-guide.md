# راهنمای کاربری وبلاگ 👤

## برای خوانندگان

- **مطالعه**: `/blog` — فهرست مقالات با صفحه‌بندی؛ جست‌وجو با `?q=…` (فارسی‌آگاه).
- **دسته/برچسب**: از نوار کناری یا لینک برچسب‌های زیر هر مقاله.
- **آرشیو**: `/blog/archive/1405/8` — ماه جلالی (ارقام فارسی هم مجاز است).
- **نظر**: فرم پایین هر مقاله؛ پس از بررسی مدیر نمایش داده می‌شود
  (در صورت تأیید خودکارِ کاربران خوش‌سابقه، بلافاصله).
- **دنبال‌کردن با RSS**: `/blog/feed` (یا `?format=atom`).

## برای نویسندگان

- از `/admin/blog/posts/create` مقاله بنویسید؛ بدنه **Markdown** پشتیبانی
  می‌شود (عنوان `##`، لیست، کد، لینک و تصویر).
- خروجی Markdown به‌صورت خودکار **escape-first** و سپس سانیتیزه می‌شود —
  هیچ HTML خامی از مقاله/نظر اجرا نمی‌شود.
- مقالهٔ پیش‌نویس فقط برای شما (و editor/admin) در پنل قابل مشاهده است؛
  پس از انتشار توسط editor عمومی می‌شود.
