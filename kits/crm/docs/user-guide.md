# راهنمای کاربر — پرتال پشتیبانی

## ثبت تیکت گام‌به‌گام

1. **ورود**: `/crm/support` — بدون نیاز به حساب کاربری.
2. **فرم**: نام، ایمیل، عنوان و متن مشکل (حداقل ۵ نویسه) را پر کنید.
3. **شمارهٔ پیگیری**: پس از ثبت، شماره‌ای مانند `TKT-20261025-A1B2C` دریافت
   می‌کنید — **آن را نگه دارید**؛ تنها کلید دسترسی به تیکت است.
4. **پیگیری**: `/crm/support/track` یا `/crm/support/{شماره}` — وضعیت
   (باز / منتظر مشتری / حل‌شده / بسته)، اولویت و پاسخ‌های تیم پشتیبانی.
5. **پاسخ**: در همان صفحه پاسخ بدهید — اگر تیکت «حل‌شده» باشد و شما پاسخ
   دهید، بازگشایی می‌شود.

## نکته‌ها

- **اولویت تیکت‌های پرتالی** توسط تیم پشتیبانی تعیین می‌شود (فرم عمومی
  همیشه «عادی» ثبت می‌شود تا صف اولویت‌ها دست‌کاری نشود).
- **SLA**: هر تیکت سررسید پاسخ دارد؛ اگر تیم به سررسید نرسد، تیکت به‌طور
  خودکار به مدیران **escalate** می‌شود (نشان ⚠ در پنل).
- **یادداشت‌های داخلی** تیم پشتیبانی هرگز در پرتال نمایش داده نمی‌شوند.
- متن ارسالی شما پاک‌سازی می‌شود (ضد XSS) — از درج HTML خودداری کنید.
- محدودیت نرخ: هر IP حداکثر ۵ تیکت و ۱۰ پاسخ در دقیقه.

## API (برای وب‌سایت/اپلیکیشن شما)

```bash
# سرنخ از فرم وب‌سایت
curl -X POST https://example.com/api/v1/crm/leads \
  -H 'Content-Type: application/json' \
  -d '{"name":"سارا احمدی","email":"sara@test.dev","title":"درخواست دمو","value":50000000}'
# ← {"data":{"lead_id":"…","score":15,"status":"new"}}

# تیکت
curl -X POST https://example.com/api/v1/crm/tickets \
  -H 'Content-Type: application/json' \
  -d '{"name":"سارا احمدی","email":"sara@test.dev","subject":"باگ","body":"…"}'

# وضعیت تیکت
curl https://example.com/api/v1/crm/tickets/TKT-20261025-A1B2C
```
