# راهنمای مدیر/مدرس — آکادمی (LMS)

## نقش‌ها (DOC-095 §4)

| نقش | توانایی |
|---|---|
| student | ثبت‌نام، یادگیری، آزمون، پرسش (بدون دسترسی پنل) |
| instructor | ساخت دوره و مدیریت **دورهٔ خود** (بخش/درس/آزمون/سؤال)، نمره‌دهی آزمون‌های دورهٔ خود، مشاهدهٔ ثبت‌نام‌ها و گزارش دوره‌های خود، صدور/مشاهدهٔ گواهی |
| assistant | نمره‌دهی **همهٔ** آزمون‌ها (grade-any)، مشاهدهٔ ثبت‌نام‌ها و دوره‌ها |
| lms-admin | همهٔ `lms.*` — دوره/دسته/ثبت‌نام/گواهی (ابطال)/گزارش |
| admin | همه‌چیز + کاربران |

Policy مالکیت: `CoursePolicy` — instructor روی دورهٔ خود + مجوزهای «همه»
(`lms.course.update/delete/publish`) برای مدیر.

## دوره‌ها — `/admin/lms/courses`

- **ساخت**: عنوان (slug خودکار فارسی)، دسته، سطح، زبان، قیمت (ریال — int minor-unit، ADR-0013) یا رایگان، خلاصه/توضیحات Markdown، **پیش‌نیازها** (چندانتخابی از دوره‌های منتشرشده).
- **ساختار**: بخش → درس (ویدیو/متن/آزمون/پیوست) با مدت، ترتیب و «پیش‌نمایش رایگان». نشانی ویدیو فقط http(s) یا مسیر نسبی (allowlist امنیتی).
- **انتشار**: فقط با حداقل یک درس. پیش‌نویس → منتشر → بایگانی.
- **دسته‌ها**: ساخت/حذف در همان صفحه (حذف دسته، دوره‌ها را بی‌دسته می‌کند).

## آزمون‌ها — `/admin/lms/courses/{id}/quizzes`

- حد نصاب قبولی (درصدی از جمع نمرات)، حداکثر تلاش، محدودیت زمان (دقیقه).
- سؤال: چهارگزینه‌ای (گزینه‌ها `key=text` هر خط)، صحیح/غلط (`true|false`)، پاسخ کوتاه (پاسخ مرجع — با `|` چندپذیرش)، تشریحی (همیشه دستی).
- اتصال آزمون به درس: در فرم درس، «شناسهٔ آزمون» را وارد کنید (نوع درس = آزمون).

## نمره‌دهی — `/admin/lms/grading`

صف تلاش‌های «در انتظار نمره» (submitted): پاسخ تشریحی + نمرهٔ دستی +
یادداشت → ثبت. نمرهٔ نهایی = خودکار + دستی؛ نتیجه با اعلان (mail+database)
به دانشجو می‌رود (`lms.attempt.graded`). مدرس فقط دوره‌های خود را می‌بیند.

## ثبت‌نام‌ها — `/admin/lms/enrollments`

فیلتر دوره/وضعیت • لغو (drop) • بازگردانی • **صدور دستی گواهی** برای
ثبت‌نام تکمیل‌شده (force — حتی اگر آزمون‌ها ناقص باشند؛ برای موارد استثنا).

## گواهی‌ها — `/admin/lms/certificates`

- صدور خودکار: تکمیل دوره + قبولی همهٔ آزمون‌ها → Workflow
  `lms-issue-certificate` (requested → generating → issued؛ تاریخچه در
  جداول workflow موتور و `workflow_instance_id` رکورد گواهی).
- serial: `TVN-LMS-XXXXXXXXXX-C` با رقم کنترل — verify عمومی بدون لاگین.
- **ابطال**: verify عمومی «⛔ باطل‌شده» نشان می‌دهد؛ سند چاپ دیگر سرو نمی‌شود.
- سند گواهی: HTML آمادهٔ چاپ (print-to-PDF — همان رویکرد PdfExporter موتور
  report) در `/lms/certificates/{serial}/document`.

## گزارش پیشرفت — `/admin/lms/reports/progress`

نمای کلی (ثبت‌نام/تکمیل/میانگین پیشرفت/نرخ تکمیل/درآمد) + جزئیات هر دوره
(جدول دانشجویان با وضعیت آزمون‌ها) + خروجی CSV (BOM + ضد CSV Injection).
مدرس فقط دوره‌های خود را می‌بیند.

## پرداخت

- دمو/توسعه: `lms.payment.driver=sandbox` (پیش‌فرض — قطعی، بدون شبکه).
- عملیاتی: `driver=engine` + `lms.payment.gateway` (zarinpal/idpay/…) +
  کلیدهای `.env` — verify همیشه server-to-server با **مبلغ دورهٔ محلی**
  (DOC-120 §5)؛ callback تکراری اثر دوم ندارد (idempotent).

## نگهداری

- `php bin/tvn lms:recompute-progress [--course=<ulid>] [--dry-run]` —
  بازشماری درصد پیشرفت/وضعیت تکمیل پس از import یا حذف درس‌ها.
