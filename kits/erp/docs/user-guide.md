# راهنمای کاربر — کیت ERP 🏭

## نقش شما چه دسترسی‌هایی دارد؟

| نقش | کارهای اصلی |
|---|---|
| حسابدار (`accountant`) | مشاهدهٔ حساب‌ها/اسناد، ثبت سند دستی (پیش‌نویس) |
| مدیر مالی (`finance-manager`) | تأیید/ثبت قطعی/ابطال سند، تأیید مالی خرید، بستن دوره، همهٔ گزارش‌ها |
| انباردار (`warehouse-keeper`) | رسید/حواله/انتقال/اصلاح موجودی، مدیریت انبار و کالا |
| کارشناس خرید (`procurement-officer`) | ساخت سفارش خرید، ثبت رسید، فاکتور تأمین‌کننده، پرداخت |
| کارشناس فروش (`sales-officer`) | سفارش فروش، تحویل، صدور فاکتور، ثبت دریافت |
| کارشناس HR (`hr-officer`) | پرسنل، کارکرد، پردازش و پرداخت حقوق |
| برنامه‌ریز تولید (`production-planner`) | BOM، سفارش تولید، شروع/تکمیل |
| حسابرس (`auditor`) | فقط خواندن: اسناد، گزارش‌ها، ردپای audit |
| مدیر ERP (`erp-admin`) | همهٔ عملیات + تأیید مدیرعامل خریدهای کلان |

## قانون طلایی سند

هر سند حسابداری باید **تراز** باشد: جمع بدهکار = جمع بستانکار
(ریالی، بدون گرد‌کردن). سند ناتراز ذخیره نمی‌شود. ردیف‌های خالی فرم
نادیده گرفته می‌شوند.

## نکات

- مبلغ‌ها **ریال** و صحیح هستند (بدون اعشار).
- مقدارهای انبار تا ۳ رقم اعشار پشتیبانی می‌شوند (کیلوگرم/متر).
- حواله با موجودی ناکافی رد می‌شود — نخست رسید بزنید.
- سند ثبت‌شده (posted) تغییر نمی‌کند — اصلاح با «ابطال (سند معکوس)».
- رسید/حواله/تحویل/تکمیل تولید → سند حسابداری **خودکار** صادر می‌شود؛
  در صفحهٔ اسناد با منبع (inventory/sales/production/hr) فیلتر کنید.
