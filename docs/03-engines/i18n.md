## ۱. هدف
ترجمه با Namespace/Domain، Pluralization، Fallback Chain، Localize تاریخ/عدد/پول،
و پشتیبانی کامل RTL — بدون وابستگی به `symfony/translation` یا `intl` (با fallback).

## ۲. API
```php
trans('shop.product.title');
trans('shop.product.discount', ['percent' => 20]);       // :percent → ۲۰
trans('shop.cart.items', ['count' => 3]);                 // pluralization
__('shop.product.title');                                  // helper
Lang::get('key', replace: [], locale: 'en');
Lang::has('key');
Lang::choice('shop.cart.items', 3);                        // plural صریح
Lang::setLocale('fa'); Lang::getLocale();
Lang::getFallback();

// Localize
trans_number(1234567.89);        // ۱٬۲۳۴٬۵۶۷٫۸۹ (فارسی)
trans_currency($money);          // ۱٬۲۳۴٬۵۶۷ ریال
trans_date($date, 'Y/m/d');      // با تقویم locale
```

## ۴. Pluralization
```php
// کلید با قوانین plural
'items' => '{0}خالی|{1}یک قلم|[2,10]:count قلم|[11,*]:count قلم',

// یا با index
'items' => 'یک قلم|:count قلم',      // singular|plural

public function choice(string $key, int $number, array $replace = [], ?string $locale = null): string
{
    $line = $this->get($key, $replace, $locale);
    $segments = \explode('|', $line);
    $index = $this->pluralizer->indexFor($number, $this->locale());
    $chosen = $this->extractFromSegments($segments, $number, $index);
    return \str_replace(':count', (string) $number, $chosen);
}
```

### ۴٫۱ PluralRules (بدون intl)
```php
final class PluralRules
{
    /** تعداد حالت‌های plural برای هر زبان */
    private const array RULES = [
        'fa' => 1,   // فارسی: فقط one/other → عملاً ۲ حالت (۰، ۱، ≥۲)
        'en' => 2,   // one, other
        'ar' => 6,   // zero, one, two, few, many, other
        'ru' => 3,   // one, few, many
    ];

    public function indexFor(int $number, string $locale): int
    {
        $lang = \substr($locale, 0, 2);
        return match ($lang) {
            'fa', 'en' => $number === 1 ? 0 : 1,
            'ar' => match(true) {
                $number === 0 => 0, $number === 1 => 1, $number === 2 => 2,
                $number % 100 >= 3 && $number % 100 <= 10 => 3,
                $number % 100 >= 11 => 4, default => 5,
            },
            'ru' => match(true) {
                $number % 10 === 1 && $number % 100 !== 11 => 0,
                $number % 10 >= 2 && $number % 10 <= 4 && ($number % 100 < 10 || $number % 100 >= 20) => 1,
                default => 2,
            },
            default => $number === 1 ? 0 : 1,
        };
    }
}
```
🔒 اگر `intl` موجود باشد → `Locale::getPluralRules` یا CLDR؛ وگرنه جدول بالا.

## ۵. Localize عدد/پول (فارسی)
```php
final class PersianFormatter
{
    private const array FA_DIGITS = ['۰','۱','۲','۳','۴','۵','۶','۷','۸','۹'];
    private const string FA_DECIMAL = '٫';      // U+066B
    private const string FA_THOUSAND = '٬';    // U+066C

    public static function digits(string|int|float $value): string
    {
        return \str_replace(\range(0, 9), self::FA_DIGITS, (string) $value);
    }

    public static function number(float|int $value, int $decimals = 0): string
    {
        $formatted = \number_format($value, $decimals, '.', ',');
        $formatted = \str_replace([',', '.'], [self::FA_THOUSAND, self::FA_DECIMAL], $formatted);
        return self::digits($formatted);
    }

    public static function currency(Money $money, bool $withSymbol = true): string
    {
        $amount = self::number($money->amount() / (10 ** $money->currency()->decimals()));
        return $withSymbol ? $amount . ' ' . $money->currency()->symbolFa() : $amount;
    }

    public static function toLatinDigits(string $value): string
    {
        return \str_replace([...self::FA_DIGITS, '٠','١','٢','٣','٤','٥','٦','٧','٨','٩'],
                            [...\range(0,9), ...\range(0,9)], $value);
    }
}
```

## ۶. Locale Resolution
```
ترتیب (اولویت بالا → پایین):
1. صریح در کد (Lang::setLocale)
2. Session کاربر
3. کاربر احراز‌شده (user.locale)
4. Header Accept-Language (با negotiate)
5. Query ?lang= (اختیاری)
6. config.app.locale
7. config.app.fallback_locale
```
```php
// Accept-Language negotiation
public function negotiate(string $header, array $supported, string $default): string
{
    $prefs = [];
    foreach (\explode(',', $header) as $part) {
        [$lang, $q] = \array_pad(\explode(';q=', \trim($part)), 2, '1.0');
        $prefs[\trim($lang)] = (float) $q;
    }
    \arsort($prefs);
    foreach (\array_keys($prefs) as $lang) {
        if (\in_array($lang, $supported, true)) { return $lang; }
        $base = \substr($lang, 0, 2);
        foreach ($supported as $s) { if (\str_starts_with($s, $base)) { return $s; } }
    }
    return $default;
}
```
