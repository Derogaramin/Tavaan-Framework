## ۳. CacheManager
```php
final class Optimizer
{
    /** @var array<string, Cacher> */
    private array $cachers = [
        'config'    => new ConfigCacher(),
        'routes'    => new RouteCacher(),
        'views'     => new ViewCacher(),
        'autoload'  => new AutoloadCacher(),
        'events'    => new EventCacher(),
        'container' => new ContainerCompiler(),
    ];

    public function optimize(): OptimizerResult
    {
        $results = [];
        foreach ($this->cachers as $name => $cacher) {
            $start = \microtime(true);
            $cacher->cache();
            $results[$name] = (\microtime(true) - $start) * 1000;
        }
        return new OptimizerResult($results);
    }

    public function clear(): void
    {
        foreach ($this->cachers as $cacher) { $cacher->clear(); }
    }
}

interface Cacher
{
    public function cache(): void;
    public function clear(): void;
    public function isFresh(): bool;       // برای invalidate خودکار
}
```

## ۴. Atomic Write (همهٔ فایل‌های کش)
```php
protected function write(string $path, string $content): void
{
    $dir = \dirname($path);
    if (!\is_dir($dir)) { \mkdir($dir, 0775, true); }

    $tmp = $path . '.' . \bin2hex(\random_bytes(4)) . '.tmp';
    \file_put_contents($tmp, $content, LOCK_EX);
    \chmod($tmp, 0644);

    // 🔒 rename اتمیک است (جلوگیری از خواندن فایل ناقص)
    if (!\rename($tmp, $path)) { @\unlink($tmp); throw new OptimizerException(); }

    // 🔒 invalidate opcache برای فایل قدیمی
    if (\function_exists('opcache_invalidate')) { \opcache_invalidate($path, true); }
}
```

## ۵. Invalidation خودکار
```php
// هر cacher یک hash از منابعش نگه می‌دارد
final class RouteCacher implements Cacher
{
    public function isFresh(): bool
    {
        $cache = $this->cachePath();
        if (!\is_file($cache)) { return false; }
        $meta = $this->readMeta($cache);
        return $meta['hash'] === $this->currentHash();     // hash همهٔ فایل‌های routes/
    }

    private function currentHash(): string
    {
        $h = \hash_init('xxh128');
        foreach ($this->routeFiles() as $file) {
            \hash_update($h, $file . '|' . \filemtime($file));
        }
        return \hash_final($h);
    }
}
```
🔒 در هر بوت، اگر `!isFresh()` → هشدار «cache قدیمی است، `tvn optimize` بزنید».

## ۶. Opcache Preload
```php
final class PreloadGenerator
{
    public function generate(string $output): void
    {
        $classes = $this->hotClasses();      // از profile یا فهرست دستی
        $lines = ["<?php", "// Generated by `tvn preload:generate` — DO NOT EDIT"];
        foreach ($classes as $class) {
            $file = (new \ReflectionClass($class))->getFileName();
            if ($file) { $lines[] = "opcache_compile_file(" . \var_export($file, true) . ");"; }
        }
        $this->write($output, \implode("\n", $lines) . "\n");
    }
}
```
🔒 در `php.ini`: `opcache.preload=/path/storage/cache/preload.php` + `opcache.preload_user=www-data`.

## ۸. امنیت
| تهدید | کنترل |
|---|---|
| نوشتن در مسیر نامعتبر | فقط `storage/cache` |
| Cache poisoning | hash + atomic write |
| خواندن cache ناقص | atomic rename |
| نشت config در cache | cache فایل‌ها در `storage` (خارج وب) |
