# ADR-0002 — مدل مجوزدهی (Licensing)

| متادیتا | مقدار |
|---|---|
| شماره | ADR-0002 |
| وضعیت | **Proposed** (نیازمند تصمیم تیم/حقوقی) |
| تاریخ | 2026-10-01 |
| سطح اثر | Global |
| مرتبط | DOC-030 (رجیستری موتورها) |

## ۱. زمینه
باید مدل مجوز هسته و موتورها مشخص شود.

## ۲. تصمیم
هنوز قطعی نشده — پیشنهاد فعلی: **Open Core** (MIT برای هسته + مجوز تجاری برای موتورهای Enterprise).

## ۳. گزینه‌ها
| گزینه | مزیت | عیب |
|---|---|---|
| MIT کامل | پذیرش حداکثری | بدون درآمد |
| **MIT هسته + تجاری Enterprise (پیشنهادی)** | Open core، درآمد از موتورهای سازمانی | پیچیدگی مرز |
| GPL | copyleft | محدودکننده برای استفادهٔ تجاری |
| کاملاً تجاری | کنترل کامل | پذیرش کم |

## ۴. پیشنهاد
- هسته (`core/`) + موتورهایی که همه نیاز دارند (http, db, orm, cache, auth, …): **MIT**.
- موتورهای Enterprise (workflow پیشرفته، report پیشرفته، admin generator، پشتیبانی خاص): **مجوز تجاری**.
- مرز دقیق در زمان Release 1.0 تعیین شود.

## ۵. پیامدها
- فایل LICENSE در هر موتور.
- `module.json` → `license`.
- شفافیت برای کاربران.

## ۶. اعتبارسنجی
- ⏳ نیازمند تصمیم تیم/حقوقی قبل از Release 1.0.
