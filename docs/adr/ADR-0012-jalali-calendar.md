# ADR-0012 — تقویم جلالی در موتور i18n (نه پکیج خارجی)

| متادیتا | مقدار |
|---|---|
| شماره | ADR-0012 |
| وضعیت | **Accepted** |
| تاریخ | 2026-10-01 |
| سطح اثر | Engine (jalali) |
| مرتبط | DOC-070 |

## ۱. زمینه
بسیاری از کاربردهای هدف (فروشگاه، ERP، پرتال خبری ایرانی) نیاز به تقویم جلالی دقیق دارند.
پکیج‌های رایج (`morilog/jalali`، `verta`) وابستگی خارجی‌اند (نقض P1) و دقت/نگهداری متغیر است.

## ۲. تصمیم
تقویم جلالی/قمری به‌صورت **خودنوشته** با الگوریتم دقیق (Ahmad Jalali / jdf، الگوریتم ۳۳‌ساله)
در موتور `jalali` پیاده‌سازی می‌شود. اگر `ext-intl` موجود باشد برای مقایسه/تأیید استفاده می‌شود،
اما هسته به آن وابسته نیست.

## ۳. گزینه‌ها
| گزینه | مزیت | عیب |
|---|---|---|
| پکیج خارجی | آماده | نقض P1، کنترل کم |
| **خودنوشته (انتخابی)** | صفر وابستگی، کنترل کامل، دقت تأییدشده | نیاز به Test Vectors گسترده |

## ۴. پیامدها
- `engines/jalali` با الگوریتم‌های j2g/g2j/isLeap.
- Julian Day به‌عنوان پل تبدیل برای همهٔ تقویم‌ها.
- 🔒 تست Vector-Based گسترده (۱۰٬۰۰۰ تبدیل) — حیاتی برای دقت.

## ۵. اعتبارسنجی
- 🧪 ۱۰۰٪ تطبیق با `intl` (وقتی موجود است) روی ۱۰٬۰۰۰ نمونه (AC-JALALI-02).
- 🧪 همهٔ Test Vectors مرجع پاس (AC-JALALI-04).
